projects/Cybersecurity-home-lab

Cybersecurity Home Lab

  • Built a physical three-machine Linux lab on static IPv4: a Kali attacker, a Debian target and a macOS observer, all managed over SSH with ED25519 key authentication.
  • Ran active reconnaissance with Nmap to map the target, then assessed the services it exposed.
  • Hardened the Linux server with SSH configuration changes and the ufw firewall, then attacked it with a Hydra SSH brute force.
  • Detected the attack with SIEM tools like Wazuh, studied the traffic in Wireshark and tcpdump, and shut it down with Fail2Ban. Every phase is written up with findings and mitigations.

projects/Azure-Kerberos-AD-lab

Azure Kerberos & AD Lab

  • Built a segmented Azure network from scratch: a resource group, role-based subnets and a network security group on each one denying all inbound internet traffic.
  • Promoted a Windows Server 2022 machine to a domain controller (AD DS, DNS and the Kerberos KDC) for a new forest, then joined a Windows 11 client to the domain.
  • Captured a real Kerberos exchange with klist, a TGT and a service ticket, and matched both to Windows Security events 4768 and 4769 on the domain controller.
  • Debugged real problems as they came up, a DNS misconfiguration, a stuck Run Command extension and RDP permission errors, and documented each fix.

projects/malware-detector-ml

Malware Detection with Machine Learning

  • Built a machine learning classifier using Gradient Boosted Decision Trees using LightGBM binary classification model to distinguish between benign and malicious Windows PE files.
  • Extracted and prepared 32 unique numerical features from Windows PE files, including entropy, file size, imported functions, and file metadata
  • Evaluated performance using accuracy, precision, recall, F1 score, ROC AUC, and confusion matrices, achieving 94.11% test accuracy and 98.59% ROC AUC.
  • Analyzed feature importance using LightGBM's gain and split-count metrics to investigate which file characteristics contributed most to the model's predictions.
